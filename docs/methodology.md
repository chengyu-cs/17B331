# 语料采集、清洗与标注方法

> 本库怎么来的：采集原则、清洗漏斗、标注口径。想给自己家做"文字考古"的，照着来就行～
> 注：这批语料最初为一个"AI 人格模拟"研究项目整理，方法论上有社区 skill 的启发（见文末致谢），但所有数据采集与加工均为本项目独立完成。

## 一、采集原则

规矩先立好：只碰公开的、一手的、带出处的。

- **只采公开一手来源**：微博公开页、B站公开视频（字幕/CC/弹幕不用）、抖音、公众号文章、小红书、公开演出现场录音转写。不登录、不抓私密内容、不抓任何第三方粉丝站。
- **逐条带出处**：每条保留 `source_url`（或可回溯 BV 号）、`date`、`platform`、`checksum`。
- **平台原始采集稿不发布**：含他人发言与敏感期内容，只在内部留存；对外只放清洗后的公开安全池。

## 二、清洗漏斗（34,341 条主池的来源）

洗了四遍。一遍比一遍严。

1. **说话人归属**：视频字幕段做说话人标注（谁在说），只有归为她本人的段入池；主持人/嘉宾/粉丝发言剔除。
2. **置信度阈值**：说话人归属置信度 ≥0.72 入池；例外（5 个视频共 46 条连续段 0.65）如实保留并披露（见 stats.md）。
3. **公开安全过滤**：私生活/家庭/恋爱/健康细节/2020 争议/未公开作品/歌词原文一律不收录。她本人在 2020 年发的音乐/舞台/成长类公开内容保留（`sensitive_period` 字段可查）。
4. **去重与校验**：文本去重 + checksum 校验，同一内容跨平台保留各平台条目并标 `is_compilation`。

## 三、分层结构

洗完的怎么摆，一层一层说。

| 层 | 文件 | 说明 |
|---|---|---|
| 清洗层主池 | `data/corpus_public_safe_all.jsonl` | 全量公开安全条目 |
| 子集 | `data/weibo_public_safe.jsonl`、`data/concert_talking.jsonl` | 微博带原链；现场讲话 |
| 提炼层 | `refined/facts.json` | 事实卡，二手来源逐条标"待核" |
| 分析层 | `analysis/` | 风格统计/文风指南/逐条风格标注/精选证据/场景样例 |
| 索引 | `index/` | 按视频/按月导航 |

## 四、风格标注口径（`analysis/style_labels.jsonl`）

她怎么说话，量化成这些字段～

每条一个 JSON：`era`（年代分箱）、`len_bin`（句长档）、`person`（人称）、`first_person/we/second_person`（计数）、`metaphor_domains`（隐喻域，如"宇宙/舰""信/回音"）、`rhetorical_actions`（设问/感叹等）、`has_emoji / has_exclamation`。与主池按 `id` 关联（约 80% 可直接 join；其余指向未发布的早期内部版本条目，仅标签不含文本）。

## 五、方法论致谢（透明披露）

这段必须写。借了思路就要说，一条条摆在下面。

本项目整理语料与做风格分析时，参考了社区公开的 6 个 skill 的**方法论**（只借思路与流程，未复制其内容、未运行其采集/生成运行时、未使用其对其他艺人的任何整理产物）：

| Skill | 借了什么 | 明确不借什么 |
|---|---|---|
| 女娲（nuwa） | 六维证据框架、三重验证（跨域复现/生成力/排他性）、评分卡思路 | "输入人名自动造人"的运行时；网络搜索优先的采集 |
| 同事（colleague） | 五层画像结构、每条结论绑定证据 ID 的纪律 | 私有聊天记录/职场语境 |
| 仓颉（cangjie） | 长内容切分 → 观点/原则/案例三层抽取 | 书籍/播客通用模板 |
| 博主蒸馏器（distilly） | 全量语料 → 创作指南的流程 | 自动爬取/自动发布 |
| chat_with_me | 对话模式设计的参考 | 其采集器 |
| blogger-distiller | 风格规则提炼的参考 | 同上 |

感谢这些 skill 的作者把方法做成了可复用的形式。以上如有出入请提 issue。

## 六、复刻建议（给想做"文字考古"的其他圈子）

想做的话，四条血泪经验，拿去～

1. 先盘来源！！你手里真正"她/他本人说"的文本有多少，分平台、分语域数清楚。别一上来就爬；
2. 视频字幕最大的坑是说话人归属。阈值宁可高一点，例外如实披露。别放宽！
3. 公开安全过滤要在入池时做。事后补？所有计数和索引全得重算，血泪教训；
4. 逐条带出处，这是一切信任的底。引了社区二手整理的部分，要么不发，要么一条条标"待核"。别含糊～

照着做，你也能给你家攒出一份。加油！！
