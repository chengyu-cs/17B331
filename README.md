# 黄霄雲公开语料库

> Huaxiaoyun (Huang Xiaoyun) Public Corpus — fan-compiled, machine-readable.
> 34,341 条 / 37 万汉字 / 2014-09 → 2026-10 / 全部为她本人的公开发言文本。
> 维护者：雲渡星海

## 这是什么

一份从**公开平台一手采集**、清洗、去噪后的黄霄雲本人文字语料，机器可读（JSONL），每条带原始链接或可回溯 ID。适合做：考古检索、时间线核对、数据可视化、文字向二创工具、语言/AI 研究。

## 不是什么（重要）

- **不是**从任何粉丝站搬运的内容——本库数据全部直接采集自微博/哔哩哔哩/抖音/公众号/小红书/演唱会现场的公开页面，采集时未参考、未抓取任何第三方粉丝站的整理成果（关系声明见下）。
- **不是**她的全量发言——入池前做了公开安全过滤：私生活/家庭/恋爱/健康/争议/歌词原文一律未收录。
- **不是**官方发布。

## 目录结构

```
data/
  corpus_public_safe_all.jsonl   # 清洗层主池：全部 34,341 条（含平台/日期/原文/链接/使用策略字段）
  weibo_public_safe.jsonl        # 微博子集：2,408 条（带原微博链接）
  concert_talking.jsonl          # 演唱会现场讲话 14 条
refined/
  facts.json                     # 提炼层：10 条结构化事实卡（巡演/作品等），
                                  # 每条带 source_check 字段区分"主池可回指来源"与"二手待核来源"
index/
  by_video.json                  # B站 128 个视频的段落索引（考古导航用）
  by_month.json                  # 按月条目数
docs/
  fields.md                      # 全字段说明
  stats.md                       # 统计
```

**分层说明**：`data/` 是清洗后的公开安全池（原始未清洗采集稿不发布——含他人发言与敏感期内容，且 ASR 噪声大无使用价值；清洗漏斗见 stats.md）。`refined/` 是在主池之上初步提炼的事实卡；其中引用 `timeline.json`/`entities.json`/`C-011` 的来源属**二手/待核**（社区年表或粉丝剪辑），已逐条标注在 `source_check.second_hand_or_pending`，使用时请自行向主池原文或官方渠道复核。**每个目录内都有独立的 README.md 说明**（data / refined / index / docs 各一份）。

## 快速上手

```bash
# 搜含"面包"的微博（原文带链接）
jq -r 'select(.platform=="weibo") | select(.text|contains("面包")) | [.date, .text, (.source_url // .provenance.url)] | @tsv' data/corpus_public_safe_all.jsonl | head

# 看某视频下的全部字幕段
jq -r 'select(.id|startswith("bili-BV1C54y127u6")) | .text' data/corpus_public_safe_all.jsonl

# 按年份统计条目
jq -r '.date[0:4]' data/corpus_public_safe_all.jsonl | sort | uniq -c
```

B站条目的 `source_url` 由条目 ID 中的 BV 号推导（指向原视频）；微博大号条目 `source_url` 为原微博链接，小号（alt 账号，804 条）的链接在 `provenance.url` 字段。

## 来源与独立性声明

1. 全部数据由本库维护者于 2026-10 期间从公开平台直接采集（微博公开页、B站公开视频字幕、抖音、公众号文章、小红书、公开演出现场录音转写），逐条保留 `source_url` 或可回溯 ID、日期与校验和。
2. 本库**未收录**任何来自第三方粉丝站的内容。项目内部曾有一份参考社区年表整理的时间线草稿（其中 344 条引用了外部年表做时间辅助），**该草稿未包含在本开源库中**，也不会发布。
3. 字幕段带说话人归属置信度（`speaker_confidence`），入池阈值为 ≥0.72（例外披露：5 个视频共 46 条连续字幕段为 0.65，未剔除、如实保留，见 stats.md）；主持人/他人发言已剔除。
4. 41 条来自粉丝剪辑视频（2018 艺考专访）的段落标记为 `generation_allowed_paraphrase_only`：引用时请转述、勿逐字长引，并注明该视频为粉丝剪辑、单来源。
