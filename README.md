## 这是个啥

她十二年公开发言的**文字版**：微博、B站视频字幕、抖音、公众号、小红书、演唱会现场讲话——全部一手采集，洗干净，排好队，每条都带原始链接或者能查回去的 BV 号。

想做考古检索的、想核时间线的、想做可视化的、想写小工具的、想跑语言模型的——都拿去！！社区说的"考古"一直是图频考古。文字呢？没人做。那我来了。

## 先把丑话说在前面（重要）

- **不是搬运！！** 数据全部直接抓自公开平台的原始页面，没有参考、没有抓取任何粉丝站的整理成果。和社区 12 个站点什么关系、怎么避让的，下面有对照表。
- **不是全量。** 私生活、家庭、恋爱、健康、争议、歌词原文——入池前一律没收录。底线，不聊。
- **不是官方。** 粉丝整理，仅供参考，最终一切以她本人和官方为准。

## 快速上手

```bash
# 搜带"面包"的微博（原链接直接给）
jq -r 'select(.platform=="weibo") | select(.text|contains("面包")) | [.date, .text, (.source_url // .provenance.url)] | @tsv' data/corpus_public_safe_all.jsonl | head

# 看某个视频下的全部字幕段
jq -r 'select(.id|startswith("bili-BV1C54y127u6")) | .text' data/corpus_public_safe_all.jsonl

# 按年份数条数
jq -r '.date[0:4]' data/corpus_public_safe_all.jsonl | sort | uniq -c
```

B站条目的 `source_url` 是从条目 ID 里的 BV 号推出来的，指回原视频；微博大号带原链接，小号（804 条）的链接在 `provenance.url`。
